# Velstra Boutique Reviews

Trustpilot-style review profile site for `velstraboutiquereviews.com`.

## Files

- `index.html` — public review page
- `reviews.json` — review dataset
- `robots.txt` — crawler rules
- `sitemap.xml` — sitemap for final domain
- `llms.txt` — AI-crawler summary
- `vercel.json` — Vercel static hosting config

## Updating reviews

Edit `reviews.json`, commit, and push. Vercel will redeploy automatically.

## Final domain

Target: `https://velstraboutiquereviews.com/`
